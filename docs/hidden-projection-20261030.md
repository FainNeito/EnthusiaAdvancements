A full-suite run also caught a null-check error on immutable sets; the validation was corrected. Local Java 25 `mvn clean verify` now passes 52 tests with no failures, errors or skips. Tests cover existing ABI, private-leaf validation, reused-map scrubbing, visibility failures, single-player eligibility, empty/partial snapshots, session revocation and private-only toast dispatch. Packet wrappers and players in those tests are mocks; no live packet/client guarantee is claimed.
